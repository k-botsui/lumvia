はじめに / Read me first

このZIPはソースコードです。 通常利用するアプリは、下のGitHub Releasesから、お使いのOSに合うファイルを選んでください。ソースを解凍してもLumvia.appやLumvia.exeは含まれていません。

This ZIP contains source code. To use the desktop app, choose the file for your operating system from GitHub Releases below. The source archive does not contain Lumvia.app or Lumvia.exe.

Windowsをご利用の方へ：この配布ファイルはMac用です。 Windows版は準備中です。GitHub Releasesで配布状況を確認してください。

Windows users: this is a Mac package. The Windows desktop package is in preparation. Check GitHub Releases for availability.

Macで開く

  1. この案内を閉じ、同じフォルダーにある Lumvia（Lumvia.app） を確認します。
  2. 普段使う場合は、LumviaをFinderの「アプリケーション」へ移します。
  3. アプリケーションのLumviaをダブルクリックします。準備が終わると画面が開きます。

Open on a Mac

  1. Close this guide and find Lumvia (Lumvia.app) in the same folder.
  2. For regular use, move Lumvia into Applications in Finder.
  3. Double-click Lumvia in Applications. The interface opens after startup finishes.

現在は未公証のTEST版です。 macOSが起動を拒否する場合があります。その場合は保護設定を変更せず、GitHub Releasesで配布状況を確認してください。一般向け正式版の通常起動は、まだ検証を完了していません。

This is a TEST build without Developer ID signing or notarization. macOS may block it. Keep security settings enabled and check GitHub Releases. Normal first launch of a public release has not completed acceptance testing.

Windows

デスクトップ配布版は準備中

Windows用の起動アプリはまだ配布していません。Mac用の.appや、開発者向けの.cmdからの通常利用は案内していません。

Mac

TEST packages are available. Check Apple menu → About This Mac for Apple Silicon or Intel, then choose the matching Mac ZIP or DMG. Current packages are not notarized and may be blocked.

Windows

The desktop package is in preparation. A ready-to-run Windows app is not available yet. The Mac .app and development .cmd scripts are not Windows desktop downloads.

追加のセットアップ

Mac版には必要な実行環境を同梱しています。Python・Node・Dockerの導入、コマンドやサーバーURLの入力は不要です。

データの場所

データはアプリと別の場所に保存します。アプリを終了して交換しても、この保存先は残ります。

Setup

The Mac package includes its runtimes. No separate Python, Node, or Docker installation, commands, or server URL is required.

Your data

Data is stored separately from the app. Quit Lumvia before replacing it; replacing the app preserves this data folder.
