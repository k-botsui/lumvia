# Public公開の仕様

公開するものはアプリのソース、migration、テスト、自作サンプル、現在の利用・開発文書です。ソース閲覧のみのLICENSEを適用します。改変・再配布・実行には別途許可が必要です。

公開しないものは認証情報、私的DB、動画ライブラリ、バックアップ、ログ、環境・キャッシュ、宣伝映像制作フォルダー、作業スクリーンショットと過去の個別引き継ぎ記録です。手元の素材は削除せず、gitignoreで除外します。フォルダー全体のZIPを配布せず、確認したGitの公開対象を使用します。

公開前に全依存のインストール・ビルド・検証を終え、インデックスを揃えて以下を実行します。

```sh
git add -A
python3 scripts/check_publication.py
python3 scripts/scan_secrets.py
```

CIはソース検査、全履歴の秘密情報検査、lint、型検査、バックエンドテスト、migration、本番ビルドと全依存の脆弱性監査を失敗時に停止します。GitHubで作成後はsecret scanning・push protectionを有効化し、Actionsを確認してください。

初回公開前はインデックスを最新版に揃え、公開対象を検査します。秘密情報を過去に公開した場合、履歴削除だけでなく、その認証情報の失効・再発行が必要です。

ソースのPublic公開は、アプリ・動画・データベースのインターネット公開やデプロイを意味しません。通常はloopback、自分のWi-Fiで使う任意構成は私的IPv4とHTTPSだけを許可します。

今回の公開判断は[再監査記録](PUBLIC_AUDIT.md)を参照してください。
