# リンク集の共有と復元

## 操作

1. ライブラリ全体、Shelf、または選択した項目で共有ボタンを押す。
2. 共有するリンク・区間・Shelfと、除外するアップロード項目を確認する。必要なときだけメモとShelf説明を含める。
3. 投稿の公開範囲・文字情報を共有してよいことにチェックを入れ、ファイル保存または対応するOSの共有先選択を使う。コピーもできる。
4. メールやLINEでファイルを渡す。短いリンク集は「SNS用URLをコピー」でURLを投稿する。受信者は開いたページからファイルを保存できる。URLが2000文字を超える場合は、ファイルを添付するか自分で用意したファイルURLを投稿する。共有データを文字数制限で切断しない。
5. 受け取った人は「リンク集を読み込む」でファイルを選ぶか全文を貼り付ける。内容と新規/既存件数を確認し、チェックを入れて追加する。

動画・画像・アカウント・ログは自動添付しない。私的メモ、非公開投稿や限定公開URLの共有可否は本人が確認する。保存したファイルは他者に渡ると回収できない。SNSやメールの安全判定・添付対応は各サービスに従い、偽装や検査回避は行わない。

## 形式と上限

`format: "lumvia-link-list"`, `version: 1`。`links` は対応4サービスの正規化URL、タイトル、タグ、メモ、favorite。`cells` はリンクへの参照・タイトル・整数ミリ秒区間・タグ・メモ。`groups` はShelf/Collectionの名前・説明・色とリンク/Cellへの参照。キーはファイル内の参照専用で、DB IDではない。未知フィールド・バージョン、重複キー、重複リンク、壊れた参照関係、私的/実行URL、短縮URLのネットワーク解決は拒否する。

ファイル・API入力は2 MiB、リンクとCellは各2000件、整理先は500件まで。Cellは5分以内で、受信先の保存上限も適用する。上限超過は追加前に拒否し、途中だけ保存しない。画像やバイナリ、圧縮、HTML、プログラムは含まない。UTF-8のJSONテキストとして処理し、eval/コード実行やXMLの実体展開を行わない。

## 二重登録と既存データ

サービス種別と投稿IDでリンクを照合し、追跡パラメータ・URL表記差を除く。同じリンクの同じ開始・終了区間は既存Cellを再利用する。既存のタイトル・タグ・メモ・お気に入りは変更しない。ファイル内のキー・並び順を除いた内容のHMACと、追加先ID/所属の記録を私的DBに保存する。同じファイルを重ねて読み込んでも増やさない。同時読み込みはLibraryの行ロックで直列化する。

同名で所属も同じShelfは再利用し、異なるものは「（共有2）」等を付ける。後から動画・Cell・Shelf・所属を削除した場合は、再確認して不足分を追加できる。既存の余分な所属を削除する同期機能ではない。

## バックアップの範囲

リンクと整理情報の持ち運び・バックアップ用。動画本体、カバー・ヘッダー画像、解析履歴、アップロード項目のCell、アカウント情報は復元しない。既定ではメモも含まない。完全な復元は[BACKUP.md](BACKUP.md)の方法を使う。設定の旧JSON書き出しは私的メタデータの保存用で、共有ファイルとして読み込まない。

## API

- `POST /api/v1/link-shares/export-preview`: library/shelves/collectionsと任意の選択ID・include_notesを指定。所有者の安全な共有データと除外項目を返す。
- `POST /api/v1/link-shares/import-preview`: LinkListを検証。DB変更・外部接続なし。
- `POST /api/v1/link-shares/import`: bundleと`confirmed: true`を検証してトランザクションで追加。認証・CSRF・Origin検査、頻度制限が必要。

## SNS用URLの保存ページ

既存のWorkers Free窓口の `/link-list` は静的な保存ページを配信する。共有URLは `#v1=` の後にgzipしたJSONをbase64urlで格納する。フラグメントはHTTPリクエストに含まれず、共有データをサーバーやDBに保存しない。URLを受け取った人がブラウザー内で展開し、テキストファイルを保存する。送信先サービスには利用者がURL全体を投稿するので、そのサービスと受信者には内容が渡る。秘密情報を入れる形式ではない。URLは2000文字まで、展開データは2 MiBまで。未対応ブラウザーではファイル共有に戻る。保存ページは外部通信・埋め込み・フォームをCSPで禁止し、文字情報はtextContentだけで表示する。SNSのURL変換・フィルター・削除後のリンク到達性は保証しない。

## 画像付きv2

画像なしv1は互換性を維持します。共有画面でカバー・Shelfヘッダーを含める確認を選ぶとv2になります。1画像48 KiB以下・640px以下のJPEGをbase64データとしてTXTに入れ、全体2 MiB、リンクとShelfの合計40件を上限とします。EXIFを除去し、表示位置はx・y（0〜100）、zoom（1〜3）を保持します。動画本体は含めません。受信時には外部画像URLへ接続せず、JPEGを検証・再エンコードして保存します。既存画像を上書きしません。旧版ではv2を読み込めないため、受信者も更新してください。
