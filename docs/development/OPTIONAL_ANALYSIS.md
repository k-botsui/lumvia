# 機械学習機能の撤去

2026-10-09の依頼により、人物探索・物体検出・文字起こしを現行版から外しました。画面、API、モデル実行、導入スクリプト、OpenCV等の追加依存を削除しています。設定による再有効化はできません。

動画の追加、リンク保存、公開動画の一時プレビュー、Cellの切り取りと再生、Shelf、検索は継続します。シーンの切り替わりを調べるFFmpeg処理は機械学習モデルを使わないため維持します。

保存済み動画・Cell・Shelfは削除しません。過去の解析由来を壊さないため、旧DBテーブルと移行履歴は互換記録として保持します。旧モデルの待機ジョブは実行せず、再試行も拒否します。旧解析結果は通常の検索や画面へ出しません。

将来の発展版として再検討する場合は別の設計変更として扱います。現行方針は[ADR 0006](../adr/0006-focus-and-devices.md)、旧版の歴史は[ADR 0003](../adr/0003-local-person-scenes.md)に記録しています。
