# ADR 0008: 確認付きのリンク集ファイル

## 決定

外部リンクとCell/Shelf構成を、バージョン付きのJSONを格納するUTF-8テキストファイル `lumvia-links.txt` で持ち運ぶ。短いリンク集には、既存Workers窓口で静的保存ページを配信し、gzip/base64urlのデータをURLフラグメントへ入れるSNS用URLを提供する。新しい有料ホスティング、公開トークン、共有DB、XML解析、ZIP展開を導入しない。既存の私的メタデータ書き出しとは別の許可フィールドだけを使う。

送信前に対象・除外項目と実際のURL/文字情報を表示し、確認を必須にする。メモ・Shelf説明はopt-in。アップロードMediaとそのCell、Asset、カバー・ヘッダー画像、認証・利用者ID・DB ID・パスは書き出さない。外部リンクの公開範囲や権利は自動認定しない。

読み込みは厳密な型・バージョン・参照関係・件数・2 MiB上限を確認し、確認画面ではDBを変更しない。対応サービスの投稿URLをネットワークアクセスなしで正規化し、既存リンク/区間を再利用する。タイトル等を上書きしない。LibraryロックとHMAC付きの永続受付記録で、同時送信・再送・データの順序変更による二重登録を防ぐ。Shelfの同名衝突は内容が同じ場合は再利用、異なる場合は別名を付ける。削除された項目や所属は確認後に再追加できる。

## 限界

外部サービスの削除・非公開化でリンク先が再生できなくなる場合がある。画像は再現しない。完全バックアップには従来の私的バックアップが必要。SNSの添付対応や文字数制限、セキュリティ判定を保証・回避しない。公開ファイルの配布先管理は利用者が行う。
