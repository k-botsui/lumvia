# 0003: 明示的に登録した人物の登場候補をローカルで探す

過去の設計記録: 2026-10-09。同日の依頼により現行版から撤去。現在の方針は[0006](0006-focus-and-devices.md)を参照。

旧版での採用: 2026-10-09。対象はこのMacでの私的利用。公開・商用展開の審査完了を意味しない。

ユーザーから人物の登録・機械学習による登場シーン探索を依頼され、優先対象を「推しなど人物の登場シーン」と確認した。憲章20・21に従い、一般の物体検出とは別の任意機能として、以下をレビューした。

## 製品

所有者が名前と参照写真を登録し、動画ごとに探したい人物を選んで実行する。全動画での自動照合、公開人物データベース、本人確認、認証、センシティブな属性推定は行わない。結果は「登場候補」と類似度で示す。類似度は確率ではない。候補を確認してCellに保存し、ユーザーの名前・メモ・既存Cellを上書きしない。REFERENCEの動画本体は取得せず、探索は手元から追加したMANAGED動画に限る。

## プライバシー

元の参照写真は一時領域だけで処理し、整列した顔画像と128次元の特徴量を私的ストレージ・DBへ保存する。特徴量は生体情報に相当する機微なデータとして扱い、API応答・通常のJSON書き出し・ログに含めない。画像と動画は外部の推論APIへ送らない。人物登録の削除で画像、特徴量、対応候補を削除する。保存したCellは所有者が作成した記録として残る。解析中の削除は拒否し、処理停止後に行う。

DB・ファイルにはアプリ独自の保存時暗号化を設けていない。OSのアクセス制御・FileVault・バックアップ保護は別の境界であり、OSのiCloud等の同期をLumviaが制御するものではない。私的バックアップには特徴量・顔画像も含まれる。削除前のバックアップは別途管理する。

## セキュリティと資源

- 所有者認可、CSRF/Origin検証、別ユーザーは404。人物画像は認証付き配信。
- JPEG・PNG・WebPの静止画像のみ、2 MiB・縦横4096px以内。EXIF等を除去して再エンコード。画像の同時デコードは2件、登録のモデル実行は1件。
- 登録20人、1回5人、1フレーム最大8顔、3秒以上の間隔で最大300フレーム。短い登場や小さい顔を見逃すことがある。
- OpenCVはCPU1スレッド、モデル実行は分離プロセス、登録20秒・探索120秒まで。人物探索は全APIプロセスを通じて同時1件。既存のジョブ・キャンセル境界を使用する。
- モデルを実行時にダウンロードしない。出所を固定し、起動ごとにSHA-256を照合する。モデル交換時は既存特徴量との版一致を要求する。
- 解析履歴は動画ごとに10件。削除して再実行できる。候補と保存済みCellは区別し、解析のモデル版・設定・時刻・由来を保持する。

## モデルの出所と利用条件

OpenCV Zooのcommit `47534e27c9851bb1128ccc0102f1145e27f23f98` に固定したYuNet 2023marとSFace 2021decを使用。セットアップスクリプトは公式ホストから重みとライセンスを取得し、ファイルサイズとSHA-256を検証する。モデルはGit対象外に置く。

| 重み | SHA-256 |

| YuNet 2023mar | `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4` |
| SFace 2021dec | `0ba9fbfa01b5270c96627c4ef784da859931e02f04419c829e83484087c34e79` |

配布ディレクトリーの表示は[YuNet MIT](https://github.com/opencv/opencv_zoo/blob/47534e27c9851bb1128ccc0102f1145e27f23f98/models/face_detection_yunet/LICENSE)、[SFace Apache-2.0](https://github.com/opencv/opencv_zoo/blob/47534e27c9851bb1128ccc0102f1145e27f23f98/models/face_recognition_sface/LICENSE)。一方、同じSFace重みの学習データと商用利用についての[確認issue #313](https://github.com/opencv/opencv_zoo/issues/313)は2026-10-09時点で未解決である。これは第三者の確認依頼であり、利用禁止を断定する根拠でも、商用利用を保証する根拠でもない。私的ローカル利用を対象とし、商用展開・再配布前には権利・適用法・同意管理を別途確認し、必要ならモデルを交換する。

## 検証と限界

公開のNASA由来の参照素材で、顔なし画像の拒否、参照写真の登録、9秒の合成動画の3〜6秒の登場候補、Cell保存、人物削除時の候補削除とCell保持を確認した。一般的な推し動画、遮蔽、照明差、多人数、誤検出率を網羅した精度評価は未実施。個人識別の正しさを保証する用途には使わない。
