# ADR 0001: ローカルライブラリを最初の実装範囲にする

- 状態: 採用
- 日付: 2026-10-09

仕様書は長期の設計憲章です。最初の実装では「追加→再生→Cell保存→整理→検索→区間へ戻る」を完全な経路として作ります。AIモデルや外部プラットフォームに依存せず便利に使えることを優先します。

Next.js/FastAPIのモジュラーモノリスと、分離したCelery workerを採用します。PostgreSQLを正本とし、RabbitMQを配信、Redisを短期レート制限に限定します。永続Job行をoutboxとして使用し、broker停止による通知漏れを修復します。

本人だけがこのMacで使うため、ループバックに限定したローカルパスワードログインを用意します。独自のトークン規格は作らず、不透明セッションを採用します。外部公開するproduction設定ではHTTPSとOIDCを要求します。実IdPとの接続検証は公開の前提作業です。

私的ファイルはローカルストレージを既定にします。S3インターフェースは同じ契約に置きますが、未接続のS3を動作確認済みとは扱いません。解析はFFmpegシーン検出を既定にし、文字起こしと物体検出はモデルを配置するまで無効にします。

外部取り込み、ワークスペース権限、アカウント削除、共有、意味検索、運用監視は今後の範囲です。ユーザーの指示によりGitHub公開・外部デプロイはしません。ライセンスも公開前に決めます。
