# 0009: 開発環境を必要としないMacアプリ

初心者の利用者にHomebrew、Python、Node.js、Dockerやサーバーの設定を要求しない。IntelとApple Siliconの両方を対象とし、macOS 12以降をビルド対象にする。対応OSの宣言はバイナリ検査と実機検証を区別する。

AppKit/WKWebViewの画面と、専用のライフサイクル管理、Node.js 22、ポータブルPython、PostgreSQL、Valkey、FFmpegをまとめる。状態と秘密情報はユーザー専用のApplication Support配下に生成し、配布物に含めない。開発データとは分離する。ポートは動的に割り当て、外部から接続できる待受やシステム全体の常駐サービスを作らない。

PostgreSQLのジョブ行を永続キューとする既存の設計を維持する。デスクトップ版のみ、最大2並列のポーリング実行器で既存の処理を実行する。ジョブ行のロック、状態遷移、期限切れリースの回復、失敗時の再試行、削除処理は既存ロジックを共有する。終了時には実行中の自分のジョブにキャンセルを要求する。開発・コンテナー版のCelery/RabbitMQは変更しない。

動画のH.264エンコードにはApple VideoToolboxを使用し、ソフトウェア利用も許可する。Mac版FFmpegはGPL・nonfree・外部ネットワーク機能を無効にし、共有ライブラリのLGPL構成でビルドする。対応ソースとビルド設定を同時配布し、Lumviaの個人利用ライセンスが第三者の権利を制限しないことを明示する。

未署名・未公証のTEST版と一般向け配布を区別する。Appleの保護機能の無効化をインストール手順にしない。Windows/Linuxの配布は、それぞれの依存とライフサイクルを検証する別の実装が必要となる。
