# ホームの構図と立体ロゴ

現行ホームは、画像を貼り付ける方式を廃止し、既存ロゴの二枚の折りをThree.jsで立体化しています。文字とロゴを同じ余白・背景へ置き、枠で二分しません。文章は「思い出を、あなただけに。」「好きな動画も、大切な瞬間も。」に絞ります。

ロゴは厚み、丸い縁、浅い曲面、青から暖かな白への色、透過と室内光の反射を持ちます。光の環境もローカルで生成し、写真、外部テクスチャ、外部の3D素材は読み込みません。白い折りの線と床の光は初回にだけ短く描きます。ポインターとスクロールに合わせて角度が少し変わり、遠近と材質の変化を見せます。

読み込み中は光の背景だけを表示します。最初の立体描画が完成してから、800msで少し浮き上がるように現れ、影と光の線も同時に始まります。平面のSVGは読み込み待ちには使わず、読み込み失敗・WebGL非対応・描画不能のときだけ表示します。動きを減らすOS設定では、描画準備後に静止した立体をそのまま表示します。

動画、保存した瞬間、Shelfは独立した横送りの列です。スワイプ、矢印、キーボードに対応し、CSS scroll-snapでカードの位置に止めます。縦スクロールを横方向へ奪いません。スマホではロゴを文章の上へ移し、次のカードを少し見せます。

`prefers-reduced-motion`では演出を止めます。3D描画は初回と角度が変わる間だけ実行し、画面外・非表示では停止します。WebGLが使えない場合は既存の形を保つSVGへ戻ります。最大描画倍率は1.5。元のブランドSVGを変更しません。

主な実装: `components/home-sculpture.tsx`、`home-scene.ts`、`content-rail.tsx`、`app/globals.css`。
