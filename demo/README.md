# Lumvia Demo

28秒のトレーラーV6です。2026-10-13に、専用デモライブラリの現在のGUIを使ってライブラリ・再生・Cell作成・Shelf・ホームを撮り直しました。飾りコピーを削除し、元の尺と音楽を維持しています。GUI部分は実際の画面キャプチャで構成しています。

`lumvia-trailer-v6-preview.mp4` は960×540、60fps、H.264/AACのプレビューです。READMEの埋め込み動画と同じ版です。
