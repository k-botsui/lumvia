# Lumvia Demo

28秒のトレーラーV6です。専用デモライブラリの現在のGUIに、再生中の映像とカメラ移動を合成しています。前回V5.2と同じ尺・音楽・場面構成を保ち、映像がカードへ収まる動き、カードから映像へ広がる動き、編集画面へのズーム、CellからShelfへ収まる動きを現在のGUIに合わせて再制作しました。立体ロゴは動かし、文字は丸みのあるLumviaの字体へ更新しています。飾りコピーは入れていません。

`lumvia-trailer-v6-preview.mp4` は960×540、60fps、H.264/AACのプレビューです。READMEの埋め込み動画と同じ版です。
