# Lumvia Demo

28秒・1680フレーム・60fpsのトレーラーV7です。V6.1の構成、尺、音楽、実写場面、立体ロゴを保ち、GUIが映る区間（0.8–6秒、12.6–21秒）だけを最新版に更新しています。実装済み画面の撮影画像に、再生映像と従来と同じカメラ移動を合成しています。新しい広告コピーは追加していません。

`lumvia-trailer-v7-preview.mp4` は960×540、60fps、H.264/AACのプレビューです。フルHD版は[TEST 7の添付動画](https://github.com/k-botsui/lumvia/releases/download/v0.2.0-mac-test.7/Lumvia-Trailer-V7.mp4)です。音声の圧縮済みパケットはV6.1と同一です。風景映像はV6.1の修正済みフレームを引き継いでいます。
